# Front Row Ticket Upgrade Challenge

A Next.js App Router and TypeScript project for the Front Row Ticket Upgrade Challenge. The core queue domain types are in `src/domain/types.ts`. The application shell is intentionally blank while Task 1 establishes the project setup.

The domain types follow the fields and suggested result shape in the assignment. No extra business rules or data fields are assumed.

## Run

- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run build` — build the application
- `npm test` — run Vitest tests
- `npm run typecheck` — check TypeScript types

## Stack

Next.js App Router, React, TypeScript, CSS, and Vitest.
